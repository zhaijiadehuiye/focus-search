关于 Focus Search

打开一个平台，本来想搜索，却被首页推荐带走。Focus Search 为此而生。

在这里输入关键词，直接前往你选择的平台搜索结果。没有热搜、资讯和推荐卡片。

背景风景为可轮换的精选图片集；不是实时图库推荐。
这是独立的搜索入口，未与 Google 或任何搜索平台建立关联。平台的登录、验证码及访问要求仍然适用；进入结果页后，平台本身仍可能显示推荐内容。

你的搜索，留给你自己

本页不使用分析统计、广告脚本、外部字体或第三方图标请求。输入时不会发送关键词；只有点击搜索，才会将关键词传给你选定的平台。

默认不保存搜索历史。若主动开启，记录仅保存在当前浏览器，关闭开关会立即删除。主题、网站和背景偏好也仅存于当前浏览器。本地背景图片使用浏览器数据库保存，不会上传；填写外部图片网址时，图片提供方会收到常规图片请求（不含搜索词）。

网站由 GitHub Pages 托管，托管方可能保留常规访问日志。目标搜索平台按各自的隐私政策处理搜索请求。本页不会绕过平台登录或屏蔽平台结果页上的推荐。
